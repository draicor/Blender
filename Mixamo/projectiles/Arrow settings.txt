In aseprite, I removed the background to reduce the size, then I lowered all of the arrow sprites 7 pixels south, so they are exactly centered in a 128x128 canvas, set the grid to 64x64 grid in aseprite and copied the 128x128 around the arrow and pasted it over a single 512x1024 canvas in a new aseprite file, to create the 32 directions (11.25° difference) for the arrow projectiles.

We could re use this for a fire arrow, but we would need to have an animation with fire at the tip, and possibly end up having a 4-8 frames animation for each of the 32 directions, resulting in a 512-1024px x 4096 sprite sheet for a single type of projectile, fire arrow in this case!
